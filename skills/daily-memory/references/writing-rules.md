# 写入规则

## 写入判断

**应写入**：
- 用户明确说"记一下""保存""以后记得""记录"。
- 长期偏好、稳定习惯、反复出现的话题。
- 对后续闲聊有帮助的背景信息。
- 重要生活事件、阶段性变化。

**不写入**：
- 一次性玩笑或无后续价值的闲聊。
- 技术/项目/代码相关（仍用 `memory` skill）。
- 未经用户确认的助手推断。
- 身份证号、手机号、住址、账号密码等敏感原文。
- 他人隐私的完整细节。

## 话题创建

- 话题名用用户原话中的自然关键词，简洁命名，不超过 20 字。
- 话题名支持中文/英文。
- 创建话题时同步做三件事：
  1. 创建 `memories/<话题名>/` 目录
  2. 创建当月文件 `YYYY-MM.md`
  3. 在 `references/main-memory.md` 添加话题索引

## 条目格式

```markdown
### YYYY-MM-DD

#### 标题

- 摘要：一句话概括。
- 事实：用户明确表达或可确认的信息。
- 用户表达：保留原意，必要时简写。
- 后续聊天提示：以后闲聊可如何自然接上这个话题。
- 关键词：词1、词2、词3
- 敏感级别：低 / 中 / 高
```

## 去重

- 写入前先检查对应话题文件最近条目和 main-memory.md 的简述。
- 已有同类信息：更新旧条目或追加为"补充"，不重复开新条。
- 用户纠正旧记忆：更新旧条目并标注"已修正"。

## 隐私

- 只保存摘要，不保存完整敏感原文。
- 人际关系信息保持克制，只记录对闲聊有帮助的背景。
- 用户要求删除时，直接删除对应条目并更新索引。
- 不把日常记忆用于技术任务推断。

## 分卷

- 主策略：`memories/<话题名>/YYYY-MM.md`
- 兜底：单文件接近或超过 10MB 时序号分卷：`YYYY-MM-01.md`、`YYYY-MM-02.md`
- 同时更新 main-memory.md 中该话题的「当前文档」指向。

## 搜索与匹配

写入和读取时都需要考虑话题匹配：

1. 优先精确匹配话题名。
2. 在 main-memory.md 索引中搜索关键词做模糊匹配。
3. 可向用户确认："之前聊过的 [话题X] 和这个相关吗？"
4. 确认匹配后再写入对应话题文件，不随意创建重复话题。

## 二次确认

每次写入前后检查：
- 是否属于闲聊/日常范畴。
- 是否值得长期保存。
- 是否重复。
- 是否泄露不必要隐私。
- main-memory.md 索引是否同步更新。
