# 酒店房型搜索

## 核心约束

**所有房型数据必须来自当前会话的实时互联网搜索。** 不凭记忆、不凭历史数据、不凭推断。

每个房型维度标注：`值 | URL/页面 | 获取时间 | 可信度`

---

## 搜索流程

### Step 1：确认目标酒店

```
已知条件判断
├─ 有酒店名 + 城市 → 直接构造 OTA 搜索URL
│   Trip.com: https://www.trip.com/hotels/list?keyword={酒店名}
│   tiket.com: https://www.tiket.com/hotel/search?q={酒店名}
│
├─ 只有楼宇名 + 城市 → 先搜索楼宇名定位酒店列表
│   从列表中找到目标酒店 → 进入详情页
│
└─ 有酒店ID → 构造详情页URL
    Trip.com: /hotels/{city}-hotel-detail-{id}/{slug}/
```

### Step 2：逐 OTA 进入酒店详情页

按优先级访问，每完成一个 OTA 即输出已采集数据：

```
1. Trip.com 详情页
   └─ 定位"选择房型" / "Room Type" 区域
      每个房型卡片含: 名称、床型、面积、价格、取消政策、早餐

2. tiket.com 详情页
   └─ 定位"Tipe Kamar" / "Pilih Kamar" 区域
      点击展开每个房型获取完整政策

3. Traveloka 详情页（常403，则用搜索摘要替代）
   └─ 搜索摘要含: 房型名 + 最低价
      如可访问详情页: "Pilih Kamar" 区获取完整信息
```

### Step 3：逐房型采集维度

每条房型必须收集以下字段，优先级从高到低：

| 字段 | 必采 | Trip.com 位置 | tiket.com 位置 | 备注 |
|------|------|--------------|----------------|------|
| 房型名称 | ✅ | 卡片标题 | 卡片标题 | 保留原始名称 |
| 床型 | ✅ | "Bed Type" 字段 | "Tipe Ranjang" | 归一化处理 |
| 价格 | ✅ | 价格区 | 价格区 | 保留原始币种 |
| 面积 | 尽量 | "Room Size" | 常不提供 | m²或sqft |
| 取消政策 | 尽量 | 政策展开区 | "Kebijakan" | 分级标注 |
| 早餐 | 尽量 | "Breakfast" | "Sarapan" | 含/不含/可选 |
| 入住人数 | 尽量 | "Max Guests" | — | 成人+儿童 |
| 景观/楼层 | 可选 | 名称中含 | 名称中含 | — |

### Step 4：房型类别标记（必须在采集时就标记）

```
房型名称关键词检测
├─ 含 Transit/Day Use/Hourly/3h/6h/12h → [钟点]⚠️，继续查详情
├─ 含 Monthly/Long Stay/Weekly → [长租]，继续查详情
├─ OTA 明确显示按晚入住、入住/退房日期、nightly stay、可过夜政策 → [过夜]
└─ 未见时长限制线索 → [时长未确认] / [疑似过夜/需复核]
```

**关键规则**：类别、床型、面积、价格只作为房型判断线索。房型去重必须结合 OTA 最新房型页的描述、取消政策、早餐、入住时长、类别等综合判断；无法确认时输出 `不确定（疑似同房型/需复核）`。

### Step 5：房型列表输出

按模板输出。未获取的字段标注 `未获取`，不推断、不编造。

## 逐 OTA 房型采集策略

### Trip.com（首选）

**页内定位**：
- 搜索列表页 → 点击酒店 → 详情页
- 详情页滚动到 "选择房型" 区域（通常在页面中段）
- 每个房型是一个卡片，含展开按钮

**采集字段提取规则**：
- 房型名称：卡片的 `<h3>` 或粗体标题
- 床型："Bed Type: 1 Queen Bed"
- 面积："22 m²" / "237 ft²"
- 价格：红色/橙色大号数字，如 "HKD 152"
- 取消政策：点击房型卡片展开 → "Cancellation Policy"
- 早餐："Breakfast not included" / "Breakfast included"

**特殊房型**：
- "Transit" 开头的房型 → 钟点房，必须标注 ⚠️
- 同一房型可能有两个价格（不可退款 vs 灵活） → 两个都记录

### tiket.com（印尼酒店首选）

**页内定位**：
- 搜索列表页直接显示房型名+起步价
- 点击 "Lihat" / "Pilih Kamar" → 详情

**采集字段提取规则**：
- 搜索列表页可提取：房型名、最低价、评分
- 详情页可提取：完整政策、设施清单
- 印尼语常见术语：
  - "Tipe Kamar" = 房型
  - "Harga" = 价格
  - "Sarapan" = 早餐
  - "Tempat Tidur" = 床
  - "Kebijakan Pembatalan" = 取消政策

**优势**：评价数据丰富，适合提取住客对特定房型的评价

### Traveloka（备用，常封锁）

- 搜索摘要可提取：房型数、最低价、评分
- 详情页访问模式：`/hotel/indonesia/{slug}-{id}`
- 常返回 403 → 改用搜索摘要碎片
- 有独立房源列表时（如 "Studio Transpark Juanda by Big Property"）可能与主列表为不同ID

### Booking.com / Agoda（最后尝试）

- Booking.com：详情页 "Availability" 区 → 房型列表含床型+政策
- Agoda：常返回空结果或404，优先级最低

## 房型采集示例

### 输入
```
示例数据不可复用为事实；实际任务必须实时重新获取。
目标酒店: {酒店名}, {城市}
已知电话: {用户提供电话或未提供}
```

### Trip.com 采集结果（实时搜索）

```
{OTA} 详情页 | URL/页面: {详情页URL} | 获取时间: {YYYY-MM-DD HH:mm} | 可信度: L1

房型列表:
1. {房型A} | {床型} | {面积} | {价格/晚} | {取消政策} | {早餐} | {人数} | [过夜]（需页面明确按晚入住）
2. {房型B Transit 3h} | {床型} | {面积} | {价格/3h} | {取消政策} | {早餐} | {人数} | [钟点]⚠️
3. {房型C Transit 6h} | {床型} | {面积} | {价格/6h} | {取消政策} | {早餐} | {人数} | [钟点]⚠️
```

### tiket.com 采集结果（实时搜索）

```
{OTA} 搜索列表 | URL/页面: {搜索页URL} | 获取时间: {YYYY-MM-DD HH:mm} | 可信度: L1

房型列表:
1. {房型A} | — | — | {价格/晚} | 未获取(列表页未展开) | — | — | [时长未确认]

注: 当前已访问页面只显示 {数量} 个房型；未确认是否展示钟点房。
```

### 未获取项

```
{OTA A}: 详情页403，搜索摘要无房型细节 → 标注"未获取(403封锁；未确认是否上架)"
{OTA B}: 当前 L1 搜索未命中 → 标注"未获取(当前L1搜索未命中；未确认是否上架)"
{OTA C}: 空返回 → 标注"未获取(空返回；未确认是否上架)"
```
