# 输出模板

## 通用原则

1. 实时证据模式下，每条数据必须标注 `URL/页面`、`获取时间`、`可信度`。
2. 纯语义理解模式下，必须标注 `纯语义判断，不等同于事实确认，不能替代实时互联网证据`。
3. 缺失字段写 `未获取`，并说明已查路径；不编造、不把未获取写成不存在。
4. 酒店和房型判断只用三分法：`重复 / 不同 / 不确定`。
5. 电话、地址、坐标、名称、床型、面积、价格等单一字段只能作为线索。

|------|----------|--------|------|--------|------|-----------|----------|----------|--------|

### 复核清单

## 标注规范

- `L0` = 用户直接提供。
- `L1` = 当前会话实时互联网搜索，必须附 URL/页面 + 获取时间。
- `语义` = 纯语义理解模式，不是事实证据。
- `未获取(当前L1搜索未命中；未确认是否在售/展示)` = 当前搜索没拿到，不表示不存在。
- `未获取(403封锁)` = 平台访问受限。
- `未获取(空返回)` = 当前访问返回空结果。
- `⚠️ 统计不显著` = 评价量 < 10。

## 禁止行为

- 不凭记忆输出酒店/房型事实。
- 不把单一平台评分写成综合评分。
- 不把单一 OTA 价格写成全网最低。
- 不写程序化规则、脚本或算法做成批判断。
- 不因电话相同推出重复。
- 不因地址相近或相同推出重复。
